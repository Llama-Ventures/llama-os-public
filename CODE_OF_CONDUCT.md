# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful and constructive. Harassment, discrimination, and abusive
behavior are not tolerated.

To report unacceptable behavior, use GitHub's private reporting on this repository,
or open an issue for non-sensitive matters. Maintainers will review and respond.
