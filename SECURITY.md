# Security & Responsible Disclosure

We take the integrity of this repository seriously.

## Reporting a concern

If you find any of the following:

- a secret, credential, or any private / non-public information;
- personal data that should not be here; or
- a security issue,

please report it **privately** using GitHub's *"Report a vulnerability"* (the
repository's **Security → Advisories** tab). If the matter is not sensitive, you may
open a regular issue instead. **Do not paste the sensitive content into a public
issue.**

## If you are featured in `vc-pantheon`

The investor profiles are **AI simulations built only from publicly available
information** and do not represent your actual views, statements, or endorsement. If
you are a profiled investor and would like your profile corrected or removed, open an
issue (or use private reporting) and we will address it promptly.

## Scope

This is a methodology repository (Markdown only) — there is no executable runtime to
patch. Content, privacy, and accuracy issues are addressed on a best-effort basis.
