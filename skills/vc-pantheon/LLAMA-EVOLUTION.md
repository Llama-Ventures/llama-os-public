# VC Pantheon — 自我进化模块 (Evolution Protocol)

> 用全球顶级投资人的投资逻辑作为标尺，持续校准和提升自身的认知体系。

## 一、核心理念

VC Pantheon 不只是评估项目的工具——它也是**用户自我进化的镜子**。

通过持续对比用户的投资逻辑与 100 位顶级投资人的框架，可以：
1. 发现自己的**认知盲区**（别人看到了我们没看到的）
2. 确认自己的**差异化优势**（我们看到了别人没看到的）
3. 追踪行业**认知前沿的移动**（顶级投资人在想什么新东西）
4. 保持方法论的**迭代更新**（不要固化）

## 二、用户投资逻辑基线

### 如何填写自己的核心标签（对标 TAG-TAXONOMY 格式）

以下为示例模板——用户根据自身基金/投资策略填写：

```yaml
my_fund:

    seed: 0-5
    series_a: 0-5
    series_b: 0-5

    public_crossover: 0-5
  
  sector_top:        # 核心聚焦赛道

  style_secondary: []            # 次要风格标签

  edge:

```

## 三、每周进化协议 (Weekly Evolution Protocol)

### 触发条件
每周一自动触发，或用户说"更新对标"时手动触发。

### 执行步骤

#### Step 1: 扫描本周信号
- 搜索 100 位投资人的最新公开动态（博客、播客、Twitter/X、新闻）
- 重点关注：新投资、公开发言中的新框架/新观点、行业预判变化
- 标注与用户当前方法论相关的变化

#### Step 2: 认知差距分析 (Gap Analysis)

```markdown
## 本周认知差距报告

### 🔴 需关注：有投资人提出了我们没考虑过的框架
- [投资人X] 在 [来源] 中提出了 [新观点/新框架]
- 这对用户的意义：[分析]
- 建议行动：[具体建议]

### 🟡 值得跟踪：行业认知前沿在移动
- [赛道X] 的共识在变化：从 [旧共识] → [新共识]
- 主要推动者：[哪些投资人在推动这个变化]
- 用户的位置：领先 / 同步 / 滞后

### 🟢 确认优势：用户的差异化依然成立
- 在 [维度X] 上，用户的观点与 [投资人Y] 一致，但比 [投资人Z] 更深入
- 我们独有的视角：[具体说明]
```

#### Step 3: 方法论更新建议

```markdown
### 建议更新

#### 投资哲学文档
- [ ] 增加/修改：[具体内容]
- [ ] 理由：[为什么需要更新]

#### DD 框架文档
- [ ] 增加/修改：[具体内容]

#### 投资人档案库
- [ ] 需要更新的投资人档案：[列表]
- [ ] 新增投资人候选：[如果有新的值得加入的投资人]
```

## 五、季度认知审计 (Quarterly Cognition Audit)

每季度做一次更深入的对标：

1. **回顾本季度所有 deal 决策**
   - 投了哪些？没投哪些？
   - 用 VC Pantheon 回测：如果用 5 位投资人评估，他们会怎么判断？
   - 与实际结果对比（如果已有数据）

2. **认知进化追踪**
   - 用户本季度形成了哪些新的投资判断？
   - 这些判断在 100 位投资人中有多少人会同意？
   - 非共识的判断 → 追踪验证（非共识但正确是超额回报的来源）

3. **Pantheon 更新**
   - 有没有新的投资人值得加入？
   - 有没有投资人的方法论发生了重大变化？
   - 有没有投资人退休/转型需要标注？

4. **输出季度报告**

```markdown
## Q[X] 认知审计

### 关键发现
1. [Finding 1]
2. [Finding 2]

### 认知进化
- 新形成的判断：[list]
- 验证中的假设：[list]
- 被推翻的假设：[list]

### 与顶级投资人的距离
- 在 [领域X] 我们已处于前沿
- 在 [领域Y] 我们需要加速
- 在 [领域Z] 我们有独特优势但尚未充分利用

### 下季度重点
1. [Priority 1]
2. [Priority 2]
```

## 六、持续更新机制

### 自动触发
- 每周一：扫描 100 位投资人的公开动态
- 每次 deal 评估后：回测 Pantheon 是否给出了有价值的不同视角
- 每季度：完整认知审计

### 手动触发
- 用户说"更新对标" / "我们跟行业比怎么样"
- 用户说"XX 投资人最近说了什么新的"
- 用户说"我们在 XX 赛道的认知够不够"

### 更新来源优先级
1. 投资人的个人博客/Substack（第一手思考）
2. 播客/访谈（深度观点）
3. 公开投资记录（行为比语言更真实）
4. 社交媒体（快速信号，但需要过滤噪音）
5. 新闻报道（二手信息，最后参考）
