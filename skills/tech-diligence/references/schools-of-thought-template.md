## 1. 流派识别

> 识别该技术方向中2-5个主要技术路线/范式。

| # | 流派名称 | 一句话定义 | 核心信仰 | 代表公司/团队 |
|:--:|---------|---------|---------|------------|
| 派1 | | | "我们相信___" | |
| 派2 | | | "我们相信___" | |
| 派3 | | | "我们相信___" | |
| 派4 | | | "我们相信___" | |

### 识别方法
流派的区分通常基于以下维度之一或多个的根本分歧：
- **表征方式**：数据用什么形式表达？（像素 vs 符号 vs 向量 vs 图）
- **学习范式**：用什么方法学？（监督 vs 自监督 vs 强化学习 vs 规则）
- **架构选择**：系统怎么搭？（端到端 vs 模块化 vs 混合）
- **规模哲学**：怎么变好？（Scale is all you need vs Structure > Scale）
- **数据策略**：数据从哪来？（互联网 vs 合成 vs 专有 vs 众包）
