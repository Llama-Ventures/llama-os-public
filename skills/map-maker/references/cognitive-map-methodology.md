# 地图方法论精要 · Cognitive Map-Making Methodology

A synthesis of cognitive map-making principles.

## Core Framework

### 1. 一以贯之的道 (The Unifying Way)

中国古人做学问，指向一以贯之的道。因为你会做饭，所以你会画画；因为你会画画，所以你会做生意。不同领域在底层可以互相滋养、互相支撑。

**For map-making**: Every domain has deep structural similarities to other domains. Look for these universal patterns when building a map — they are the real insight.

### 2. 鸟瞰能力 (Bird's Eye View)

Two ways to organize knowledge:
- **时间轴式** (temporal): Self-centered narrative, like personal experience. Non-shareable.
- **空间坐标式** (spatial): Public coordinate system, like a real map. Shareable.

The key distinction: 用时间轴编织经验 = "感性" (sensibility). 用空间布点、提供稳定参照系 = "理性" (rationality).

**Bird's eye view is not just seeing from above** — it's having an internal coordinate system so that even while walking on the ground, you know what's ahead, behind, and around you. Like a footballer who knows where teammates are without looking.

**Training method**: 有目的地看，有方法地看，有结构地看，有记录地看。(See with purpose, method, structure, and documentation.)

### 3. 分类 / 分期 / 分级 (Classify / Periodize / Rank)

研究一个东西就三个方法：分类、分期、分级。

- **分类**: Must follow consistent principles. Bad: "工人、农民、商人、医生、军人" (mixed categories). Good: By gender, by age, by profession — then subdivide within each.
- **分期**: Meaningful time boundaries that reflect structural changes, not arbitrary dates.
- **分级**: Hierarchy of importance. What deserves prominence vs. footnote status.

### 4. 暗线 (Undercurrents)

Every map needs a hidden thread — the non-obvious causal chain that connects surface phenomena. This is what makes a map more than a catalog.

**How to find the 暗线**: Ask "what changed underneath that made the surface change?" repeatedly until you find the deepest driver.

### 5. 无漏穷举 with 比例尺 (Exhaustive but Scaled)

完全穷举陷入细节，就失去了归纳能力。地图有一个比例尺的问题，过度的穷举会失去轻重。

The root-directory (树状目录) structure is "几乎是唯一正确的工作方式" — almost the only correct working method.

### 6. 后感性 (Post-Sensibility)

Three levels of cognition:
1. **本能** (instinct) — automatic action, no real perception
2. **理性** (rationality) — structured frameworks, coordinate systems
3. **感觉/直觉** (post-rational intuition) — the highest level, reached only AFTER mastering rationality

"要尽快使用理性，走过高速公路后尽快到达无人区" — Use rationality quickly to build the framework, then let intuition reveal what the framework cannot.

**For map-making**: First build the rational structure (mindmap, categories, periods). THEN look for the surprising connections, the unconventional paths (另辟蹊径), the insights that transcend the categories.

## Practical Map-Making Process

1. **Receive topic** → brain naturally forms 2-3 main axes (e.g., Chinese history + Western history + future)
2. **Choose spatial metaphor** → the physical layout suggests itself (river flowing to sea, mountain range, archipelago)
3. **Build mindmap** → tree structure with 分类/分期/分级
4. **Research** → Wikipedia overview → 1-2 auxiliary articles → identify amplification points
5. **Find connections** → cross-cutting links between branches (like 全球史 linking Western and Chinese commerce)
6. **Identify 另辟蹊径** → the unconventional insight that makes YOUR map unique

## Key Quote

地图的目的不只是知道位置，还为了知道道路。当你能够准确地定位这些关系，一条理性的道路就会呈现出来。但这条理性之路智力正常的人都能看到，往往没办法出奇制胜。真正善用地图的人会另辟蹊径——抄近路、挖密道、建立交桥。

"The purpose of a map is not just to know positions, but to know paths. A rational path will emerge — but everyone can see that path. The true map-master finds unconventional routes — shortcuts, secret tunnels, overpasses."
